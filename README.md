# Pretendard + D2Coding Font Override (Naver Whale)

Windows 11의 네이버 웨일(Whale) 브라우저에서, 일반 웹페이지 텍스트는 **Pretendard**로, 코드/고정폭(monospace) 영역은 **D2Coding**으로 강제 적용하는 확장 프로그램입니다.

- 글자 크기, 줄 간격, 확대/축소, 자간, 레이아웃은 의도적으로 건드리지 않습니다.
- 열려 있는(open) Shadow DOM 기반 컴포넌트에도 폰트를 주입해서, 일부 최신 웹앱에서 폰트가 아예 적용되지 않던 문제를 개선했습니다.
- 특정 사이트에서 폰트가 깨지거나 원래 폰트를 유지하고 싶을 때는 **제외 목록**으로 간단히 끌 수 있습니다.

## 설치 전 준비

1. Windows 11에 [Pretendard](https://github.com/orioncactus/pretendard) 폰트를 설치합니다.
2. Windows 11에 [D2Coding](https://github.com/naver/d2codingfont) 폰트를 설치합니다.
3. 폰트 설치 후 웨일 브라우저를 재시작합니다.

## 웨일에 설치하기

1. 이 저장소를 다운로드하거나 클론합니다.
2. 주소창에 `whale://extensions` 를 입력해 엽니다.
3. 우측 상단의 **개발자 모드**를 켭니다.
4. **압축 해제된 확장 프로그램 설치**(Load unpacked)를 클릭합니다.
5. `manifest.json`이 들어있는 `whale-font-override-extension` 폴더를 선택합니다.
6. 아무 웹사이트를 연 뒤 `Ctrl + F5`로 강력 새로고침합니다.

## 특정 사이트에서 끄기

일부 사이트는 폰트를 강제로 바꾸면 아이콘이 깨지거나 레이아웃이 틀어질 수 있습니다. 이런 사이트는 아래 두 가지 방법으로 제외할 수 있습니다.

### 1) 툴바 팝업에서 빠르게 켜고 끄기

- 문제가 있는 페이지를 연 상태에서 툴바의 확장 프로그램 아이콘을 클릭합니다.
- **"이 사이트에서 폰트 적용 끄기"** 버튼을 누릅니다. (다시 켤 때는 같은 버튼이 **"켜기"**로 바뀝니다.)
- 새로고침 없이 바로 적용/해제됩니다.

### 2) 옵션 페이지에서 전체 목록 관리

- 팝업의 **"전체 제외 목록 관리"** 버튼을 클릭하거나, `whale://extensions`에서 이 확장 프로그램의 **세부정보 → 확장 프로그램 옵션**으로 들어갑니다.
- 도메인을 입력하고 추가합니다 (예: `notion.so`). 해당 도메인과 모든 하위 도메인에 적용되지 않습니다.
- 목록에서 삭제하면 다시 적용됩니다.

제외된 사이트는 원래 폰트를 그대로 유지하고, 나머지 모든 http/https 페이지에는 아래 두 가지 방식이 함께 적용되어 확실하게 폰트가 유지됩니다.

- 콘텐츠 스크립트로 삽입되는 스타일
- 사이트 CSS보다 우선순위가 높은 **USER-origin** 스타일시트 (`chrome.scripting.insertCSS`)

## 동작 방식

| 파일 | 역할 |
| --- | --- |
| `manifest.json` | 확장 프로그램 설정 (권한, 콘텐츠 스크립트, 팝업/옵션 페이지 등록) |
| `font-override.css` | Pretendard / D2Coding 강제 적용 규칙 |
| `content.js` | 페이지 로드 시 제외 목록을 확인 후 스타일 주입, 열린 Shadow DOM까지 재귀적으로 스타일 주입 |
| `background.js` | 서비스 워커에서 USER-origin CSS를 탭에 재주입/제거, 제외 목록 변경 시 열려 있는 모든 탭에 즉시 반영 |
| `common.js` | 도메인 정규화, 제외 여부 판별, 저장소(`chrome.storage.local`) 헬퍼 (다른 스크립트들이 공용으로 사용) |
| `popup.html` / `popup.js` | 툴바 팝업 UI — 현재 탭 기준 빠른 켜기/끄기 |
| `options.html` / `options.js` | 옵션 페이지 UI — 제외 도메인 전체 관리 |

## 알려진 제한 사항

- `whale://settings` 같은 브라우저 내부 페이지는 변경할 수 없습니다.
- 로고, 이미지, 캔버스(canvas)로 그려지는 텍스트는 CSS로 바꿀 수 없습니다.
- **닫힌(closed) Shadow DOM**은 콘텐츠 스크립트가 접근할 수 없어 적용되지 않을 수 있습니다. (열린 Shadow DOM은 지원됩니다.)
- Google Docs/Sheets의 문서 캔버스 영역은 메뉴는 바뀌어도 문서 본문은 바뀌지 않을 수 있습니다.

## 제거하기

`whale://extensions` 에서 이 확장 프로그램을 삭제하거나 비활성화하면 됩니다.
